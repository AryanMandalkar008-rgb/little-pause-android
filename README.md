# Little Pause for Android

A small reel-awareness companion with Today, History, and Goals tabs.

## Download

Download **LittlePause-v1.4.apk** from the repository’s Releases tab, then open it on your Android phone. Android may ask you to allow your browser or file manager to install apps from this source.

## Setup

Open Little Pause and use the Goals tab to:

1. Enable Little Pause in Android Accessibility settings. The service counts larger vertical feed scroll movements in Instagram, YouTube, Facebook, and Snapchat. It does not read screen text, messages, or video contents.
2. Allow display over other apps if you want the floating counter and limit screen.
3. Optionally enable a daily suggestion notification and battery background access.

On some Realme/OPPO phones, also allow Auto launch and background activity in system settings.

## Privacy and limitations

Reel counts and settings are stored locally on the phone. Little Pause has no account, analytics SDK, or network permission. Counts are estimates: Android reports view scrolling rather than a universal “reel watched” event. Small movement is ignored, but some app versions may not report suitable scroll distance. When enabled, the daily limit screen covers the whole supported app, not just its Reels tab.

This is an early direct-download build, not a Play Store release. Use the same signing identity for later updates.
